# Photography

These are **placeholders**. Replace them with real photographs of MindMorph
students and tutors as soon as you have them — a real face from your own centre
does more for a parent's trust than any stock photo, and stock is recognisable.

To swap one: put your file in this folder under the **same filename**, keeping
roughly the same shape. Nothing in the code needs to change.

| File | Shape | Used on |
|---|---|---|
| `student-hero.jpg` | portrait, ~4:5 | Hero, right column — a face works best here |
| `student-studying.jpg` | landscape, ~4:3 | About section |
| `online-learning.jpg` | landscape, ~4:3 | "Online Tuition" column |
| `in-person-tuition.jpg` | landscape, ~4:3 | "In-Person Tuition" column |

If you change a caption or alt text, they live in `src/lib/images.ts`.
